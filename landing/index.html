Para gobiernos y equipos de salud

Una herramienta abierta. Una implementación que se acuerda.

Eudila propone un registro emocional individual con acceso a ayuda y exportaciones controladas por la persona. Una implementación institucional exige definir propósito, acceso, almacenamiento y responsabilidades antes de reunir datos reales.

01

La persona conserva una copia

Puede descargar su historial en PDF, CSV y JSON. Los archivos se generan en el navegador, sin enviarlos a un servidor adicional para producir la exportación.

02

Los límites quedan visibles

Eudila no diagnostica, no estima riesgo individual y no reemplaza atención profesional. La ayuda humana permanece disponible desde el recorrido.

03

La privacidad se diseña antes

La versión con cuenta requiere almacenamiento remoto seguro. Autenticación, permisos, RLS, retención y acceso deben comprobarse para cada implementación.

Privacidad verificable

Portabilidad no significa prometer que nunca existe un servidor.

La exportación ocurre localmente; una cuenta puede guardar registros en infraestructura remota. Diferenciar ambas cosas permite conversar con precisión sobre seguridad y control.

Lo que ya se puede recorrer

Del registro a una historia que se puede leer.

El frontend integra registro en cinco pasos, vista de hoy, calendario, detalle, evolución descriptiva y exportaciones. La vista previa guarda información solamente en la pestaña y no se presenta como una cuenta en producción.

Para desarrolladores

Código abierto para construir sin una caja negra.

Eudila se publica bajo AGPL-3.0. La interfaz usa Next.js, React y TypeScript; el repositorio incluye decisiones de producto, sistema visual, pruebas y el estado explícito de las integraciones pendientes. 

git clone https://github.com/Eudila/eudila.git
cd eudila
npm ci
npm run dev

Auditá, probá y contribuí.

Las contribuciones empiezan por un issue concreto. Priorizamos accesibilidad, seguridad, integración verificable y una experiencia móvil que conserve los límites del producto.
