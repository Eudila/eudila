# Dashboard del psicólogo

Espacio previsto para el panel del psicólogo. Todavía no contiene una aplicación ejecutable ni forma parte de los workspaces de npm.

El alcance previsto incluye lista y detalle de pacientes, invitaciones y consulta de registros compartidos con consentimiento. La persistencia, los vínculos, la revocación de acceso y las reglas de autorización siguen pendientes.

La implementación deberá consumir los paquetes compartidos de `packages/` y coordinar sus permisos con Supabase. [Arquitectura y alcance](../docs/arquitectura/README.md).
