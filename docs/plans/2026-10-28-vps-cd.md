# Despliegue continuo del VPS

**Objetivo:** después de un CI exitoso de `main`, publicar la app en el VPS existente sin perder el guardado de cuenta ni cambiar los servicios de datos.

**Arquitectura:** GitHub Actions alojado por GitHub, clave SSH dedicada con comando forzado y script instalado en el VPS. El script admite exclusivamente el SHA actual de `main`, compila una release aislada con las variables públicas existentes, verifica que las migraciones ya estén aplicadas, prueba la imagen candidata y recrea solamente `web`. Conserva la imagen, enlaces y metadatos previos; vuelve atrás si la activación falla. Las migraciones nuevas se revisan y aplican manualmente antes de publicar; el despliegue se frena si falta alguna.

**Tecnologías:** GitHub Actions existente, OpenSSH, Bash, Docker Compose y Node 24. Sin runner de repositorios públicos dentro del VPS y sin nuevas dependencias de la app.

1. Integrar los cambios ya publicados de guardado de cuenta y Google en los workspaces de `main`; conservar sus pruebas y migración. Ejecutar pruebas, lint, tipos y build; comprobar el recorrido real con Supabase local.
2. Crear `.github/workflows/deploy.yml`, `app/infra/scripts/deploy-release.sh` y `deploy-ssh.sh`. Agregar una prueba del rechazo de entradas inválidas y del rollback con comandos simulados. Verificar sintaxis y CI.
3. Instalar los scripts como archivos de root y la clave dedicada con `restrict,command=...`; guardar la privada y el host conocido en secretos de GitHub. La clave no permite shell, forwarding ni subir archivos.
4. Revisar el cambio, integrar en `main` y observar CI y Deploy. Verificar HTTPS, persistencia de cuenta, aislamiento y limpieza de las cuentas sintéticas; documentar commit, ejecuciones y rollback.

Autorizado por el usuario con «ok activalo», después de informar que primero había que integrar la persistencia de producción. Se elige reutilizar el CI y despliegue por releases existentes; un runner en producción o un nuevo servicio de despliegue agregarían acceso y mantenimiento innecesarios.
