# ANI-69 · Splash de entrada — diseño y plan de implementación

**Estado:** Done en Linear, verificado el 01/10/2026. Implementación integrada y publicada en `main` de `Eudila/eudila`.

**Objetivo:** una entrada de marca breve y salteable, disponible una sola vez por pestaña, sin retrasar el registro ni la ayuda.
**Alcance:** `prototype/`, la aplicación disponible en `Eudila/eudila`. La app Next.js aún depende de ANI-48; este código nativo puede portarse a su montaje inicial.
**Arquitectura:** reutilizar `orbMarkup(moods[3])` como símbolo Neutral en el inicio. El estado estático es el predeterminado; Web Animations API añade una entrada de 600 ms solo en la primera apertura. No hay recursos ni dependencias de ejecución nuevos.
**Tecnologías:** HTML, CSS, JavaScript nativo; una comprobación con `assert` y Playwright en navegador real.

## Diseño

El brandbook v1.0 define el orbe Neutral, cinco capas y núcleo blanco, como símbolo de Eudila. Se incorpora al inicio sobre Nube con el wordmark existente. Se elige una entrada integrada en la pantalla: frente a una pantalla superpuesta, conserva visibles y operables el registro y Ayuda; frente a una secuencia de imágenes, reutiliza el SVG sin descargar ni publicar assets del proyecto anterior.

El orbe aparece suavemente, de escala 0,94 y opacidad 0,6 a su estado final, durante 600 ms. No tiene movimiento continuo en el inicio. Un toque o una tecla terminan la entrada inmediatamente sin consumir la acción original. La navegación interna, volver desde Ayuda, recargar y el segundo uso en la misma pestaña muestran el estado final. Una pestaña nueva independiente puede mostrar la entrada nuevamente; las pestañas duplicadas o abiertas con un `opener` pueden heredar la marca de sesión y omitirla. Con `prefers-reduced-motion: reduce`, almacenamiento inaccesible o pestaña inicialmente oculta, se usa directamente el estado final. Un cambio de preferencia o esconder la pestaña cancela cualquier entrada activa.

## Criterios de aceptación

- [x] Entrada visible al abrir y final automático antes de 2 segundos.
- [x] Salteable con tacto/puntero y teclado, sin consumir la interacción.
- [x] Inicio, registro y Ayuda disponibles durante la entrada, sin esperas de red.
- [x] No se repite en navegación interna, regreso ni recarga dentro de la pestaña.
- [x] Movimiento reducido muestra el estado final y ningún movimiento.
- [x] Identidad Eudila, reflujo y ayuda sin conexión conservados.
- [x] Checks, revisión, publicación y estado Done verificados.
