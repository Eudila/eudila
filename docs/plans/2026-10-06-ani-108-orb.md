# ANI-108 · Shared orb renderer

## Contract and scope

The baseline is `bd7339e6750743f846c57cd46a1154972b1a48e5`. `PRODUCT.md`, `DESIGN.md` and `docs/design/brand-review-2026-10-04.md` define five translucent layers, subtle light edges and a stable white core. Registration currently draws flat layers; history draws one filled silhouette. Both already consume `prototype/moods.js`.

Create `app/components/mood-orb.tsx` with `MoodOrb({ mood, variant, className })`. `mood` is the existing integer 1–7. `variant` is `hero` by default or `compact`; both use the same silhouette, layers and material. The SVG is decorative because callers provide the accessible state label. `className` can replace the default dimensions, preserving the square view box. Each instance owns its gradient IDs through React `useId`.

Use the existing `--color-mood-N-orb` and `--color-white` tokens. Keep `shapePath` unchanged until the original geometry reference and the full ANI-109 acceptance criteria are available. Motion belongs to ANI-112; this increment renders a fixed orb in both variants, including with reduced motion.

1. ANI-108 introduces radial material, five light edges and the white core in registration. Node renders all seven states and checks the layer count, stable core, token references and independent gradient IDs. Build, lint and types verify Next.js integration.

Each ticket gets its own commit. There is no combined PR, merge or deployment in this worktree. Slider, actions, authentication, splash and global styles remain with their assigned owners.
