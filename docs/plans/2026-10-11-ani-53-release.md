Crear `.github/workflows/ci.yml`, usando las acciones oficiales fijadas por commit y Node 24. Ejecutar los comandos existentes: instalación reproducible, lint, tipos, formato, las seis suites Node y build explícito de preview. ### 2. Recuperar e integrar el candidato existente

Requiere ubicación del código y acceso a los proyectos.
