# ANI-64 · Plan de verificación y cierre

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** comprobar el selector Next.js con el catálogo real de ANI-50, respetar la marca y cerrar ANI-64 con evidencia verificable.

**Architecture:** conservar el selector publicado en main mediante PR #6 y el lector REST compartido. El modo real obtiene las opciones exclusivamente de Supabase; las semillas se usan como referencia de identidad y como fixtures en las pruebas existentes. El borrador conserva el UUID, sin guardar registros personales.

**Tech Stack:** Next.js 16.3.8, React 19, TypeScript, Tailwind, diálogo HTML nativo, Node test y Playwright con Python.

## Ejecución

- Línea base Node: 9/9 pasan.
- El primer arranque aislado falló porque Turbopack rechaza node_modules enlazado fuera de la raíz. Se instalaron las dependencias mediante `npm ci`, sin cambiar package.json ni lockfile.
- La prueba de cápsula falló antes del cambio y pasó después. Se verificó también Figtree Bold en el título del diálogo.
- La prueba nueva de sugerencias sin desplazar falló a 320 × 568: última sugerencia terminaba en 565.4 px, debajo del main que termina en 507 px. Los ajustes de espacio conservan texto/tamaño táctil; se repite la comprobación después del cambio.
- Supabase CLI 2.120.0 inicializó un proyecto temporal vacío, PostgreSQL 17, Auth, Kong y PostgREST; aplicó la migración/semilla publicadas de ANI-50. Variables y logs temporales no se publican.
- La prueba real falla explícitamente si faltan URL/clave pública. Configurada con el anon JWT del proyecto local, pasó en Chrome sin interceptar REST: 21 filas exactas de ANI-96, seis sugerencias, selección/alternativas/UUID, teclado/foco/Escape, búsqueda, recarga, siguiente y reflujo. SQL directo confirma PostgreSQL 17.11 y 21/6/15 filas.
- `uv run --with playwright python app/registro/emociones.test.py`: exit 0, incluidas seis sugerencias visibles y objetivos ≥44 px a 320/390/520, cápsula ≥50 px, Figtree Bold, 200%, errores/timeout/reintento y ausencia de configuración.
- `node --test prototype/catalog.test.mjs data/catalogo.test.mjs prototype/flow-state.test.mjs app/historial/records.test.mjs`: 10/10, sin fallos.
- `npm run lint`, `npm run typecheck`, `npm run format:check` y build: exit 0. Build con `NEXT_PUBLIC_FRONTEND_PREVIEW=true` y `uv run --with playwright --with pypdf python app/frontend.test.py`: exit 0; recorrido de producción sin regresiones de registro, edición, preview, historial y exportaciones.
